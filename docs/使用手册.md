# 使用手册

按顺序做完这几步就行。全程大概 15 分钟，其中大部分时间是脚本自己在翻页。

## 0. 第一次用：装环境

1. 装 Node.js 22 或更新版本（https://nodejs.org ，选 LTS）。
2. 装 Python 3.9+，安装时勾上 **Add Python to PATH**。
3. 打开终端，进项目目录：

   ```powershell
   cd <项目目录>
   python -m pip install -r requirements.txt
   pwsh -File scripts\check-env.ps1
   ```

   体检报告里 `[BAD]` 的项先解决掉，`[WARN]` 的可以先不管。

> 提示：本机如果 `python` 命令跑不起来，用 `-Python` 参数指定解释器完整路径，例如
> `pwsh -File scripts\run-daily.ps1 -Python "C:\Python312\python.exe"`。

## 1. 启动一个「可被接管」的 Chrome

```powershell
pwsh -File scripts\start-chrome.ps1
```

它做三件事：用一个独立数据目录启动 Chrome、打开调试端口 9222、打开生意参谋首页。

- 这个 Chrome 和你平时用的浏览器**互不干扰**，登录态存在独立目录里。
- **第一次必须手动登录一次生意参谋**，之后不用再登。
- 已经在跑的话再执行一次不会重复启动，会直接告诉你「端口已在运行」。

## 2. 打开榜单页

```powershell
pwsh -File scripts\open-rank.ps1
```

会在后台新开一个标签页，地址取自 `config/collect.json` 的 `榜单页`，默认是：

> 手机保护套/壳 · 实时 · 淘宝 · 不限价格 · 交易总量榜

确认一下页面上：**统计时间 = 实时**、**店铺类型 = 淘宝**、**价格带 = 不限价格**。
如果店铺类型不对，点一下「淘宝」即可（或 `node tools/cdp.mjs clicktext market_rank 淘宝`）。

## 3. 跑采集和出图

```powershell
pwsh -File scripts\run-daily.ps1
```

这一条命令依次做：

1. 确认 Chrome / 打开页面 / 选中淘宝
2. 采集「交易总量」榜 10 页（100 条）
3. 这个榜出带编号大缩略图 + 清单
4. 切到「交易增速」榜，同样采集 + 出图
5. 两榜合并去重，按 5 个档位分别出图
6. 每档切一版看图切片

跑的过程中终端会实时打「第 N 页：xx 条（累计 xx）」，**盯着看**：
如果某一页条数明显变少或者报「下一页按钮不可用」，说明翻页到头或页面出问题了，脚本会自己停。

## 4. 看结果

结果都在 `data\<日期>\` 下面：

```
data\20261010\
├─ 采集-交易总量.jsonl              原始采集（每行一个商品）
├─ 采集-交易增速.jsonl
├─ 汇总图-交易总量\                 这个榜的大缩略图 + 清单
├─ 汇总图-交易增速\
└─ 汇总图-合并-实时淘宝\
   ├─ 汇总-合并-实时淘宝-01.jpg     两榜合并后的总图
   ├─ 清单-合并-实时淘宝.csv        带商品链接的完整清单
   ├─ 250以上\  100-250\  50-100\  10-50\  1-9件\
   │  ├─ 汇总-<档>-01.jpg           这一档的大图
   │  ├─ 清单-<档>.csv              这一档的清单
   │  └─ _看图\<档>_看图_01.jpg      能直接看清的切片
```

**怎么看**：

1. 先打开 `_看图\` 里的切片扫一遍（这是给人眼看的那一版）。
2. 记住想做的几格编号。
3. 打开对应的 `清单-<档>.csv`，按「排序」找编号 → 拿「商品链接」和「店铺」。

## 5. 想只抓某一天 / 某个类目

- **换日期**：在页面上点「统计时间」里的「日」并选好日期，再单独跑：

  ```powershell
  node tools/collect-pages.mjs --tab market_rank --pages 10 --reset --tag 日榜 --out "data/采集-日榜.jsonl"
  ```

  采集脚本只读页面当前内容，不关心你选的是哪天。

- **换类目**：改 `config/collect.json` 的 `榜单页`（把 `cateId` / `parentCateId` 换成目标类目），
  重新跑 `open-rank.ps1` 即可。

## 6. 按规则先过一遍标题（可选）

`filter-feilin.mjs` 用规则（图案词 / 排除词 / 买家数档）先过一遍标题，把候选和「需要看图确认」分开：

```powershell
node tools/filter-feilin.mjs "data\采集-交易总量.jsonl" "data\筛选\候选"
```

产出 `-候选.csv` / `-候选.md` / `-待看图.json`。规则在 `config/filter.json`。
注意：**标题只够排掉明显不是图案的**，真要判断有没有图案还是得看图 —— 所以主流程是出图给人看，
这一步只是可选的粗筛。
